# XDJ-AZ на Raspberry Pi 5

[English](README.md) · **Русский** · [Українська](README.uk.md)

Штатный плеер XDJ-AZ (прошивка **1.30**) на Raspberry Pi 5 с пультом
**DDJ-GRV6** (4 деки) или **DDJ-FLX4** (2 деки). Это тот же плеер, что работает
в самом AZ: его экран, браузер библиотеки rekordbox, волны, hot cue, лупы,
Beat FX, синхронизация. Всё, чего у Pi нет по сравнению с AZ (микроконтроллеры
панели, аппаратный микшер, ядро деки), заменяют программы из этого репозитория.

От «у меня есть образ 1.30» до Pi, который загружается сразу в плеер, — одна
команда.

## Что понадобится

| | |
|---|---|
| Raspberry Pi 5 | 4 или 8 ГБ; карта или SSD от 32 ГБ (плеер сам заводит себе кеши на ~10 ГБ) |
| Raspberry Pi OS Lite **64-bit** (Debian 13 trixie) | без рабочего стола: экран и пульт держит плеер. Пользователь с `sudo` без пароля (так у первого пользователя Pi OS по умолчанию), в группах `audio`, `video`, `input` |
| Экран | HDMI; настроено под сенсорную панель 1024×600. Другой экран — см. [Другой экран](#другой-экран) |
| Пульт | DDJ-GRV6 или DDJ-FLX4 по USB. Если подключены оба, берётся GRV6 |
| Образ прошивки | `XDJAZv130.iso` — **расшифрованный** образ обновления 1.30 (ISO 9660, метка `UsbAuto`). Не входит в репозиторий |
| Ключ OneLibrary | файл с одной строкой. Без него на флешке видны только папки, без плейлистов и библиотеки. Ключ один для всех дек; наш взят из проекта [AZ-MODS](https://github.com/Kyle-Hosman/xdj-az-mods), который им открывает библиотеку в своём эмуляторе. Не входит в репозиторий |
| Флешка | экспорт rekordbox с OneLibrary (`PIONEER/rekordbox/exportLibrary.db`); старый `export.pdb` плеер 1.30 не читает |
| AZ-MODS (по желанию) | `mods-vX.Y.Z.tar.gz` из релизов [AZ-MODS](https://github.com/Kyle-Hosman/xdj-az-mods): Mod Menu, стемы, редактирование плейлистов, темы |

## Быстрый старт

**1. Pi.** Запишите Raspberry Pi OS Lite 64-bit через Raspberry Pi Imager,
включите SSH. Загрузитесь, подключите экран и пульт.

**2. Репозиторий, образ и ключ на Pi** (`pi` — адрес вашего Pi):

```sh
ssh pi git clone https://github.com/r1x0s/xdjaz-pi5-kit
scp XDJAZv130.iso onelibrary.key pi:
scp mods-v1.2.8.tar.gz pi:          # для AZ-MODS
```

**3. Установка** (на Pi):

```sh
cd ~/xdjaz-pi5-kit
sudo ./scripts/setup-pi.sh --iso ~/XDJAZv130.iso --key ~/onelibrary.key
#   + --azmods ~/mods-v1.2.8.tar.gz   для AZ-MODS
```

Скрипт ставит пакеты, достаёт из образа файловую систему плеера в
`/opt/xdjaz/rootfs` (и проверяет, что это 1.30), собирает наши программы прямо
на Pi, раскладывает всё по `/opt/xdjaz` и ставит службу `xdjaz.service`.
Несколько минут, в основном `apt`. Запускать можно повторно: пересобирает и
переустанавливает всё, кроме самого плеера и его настроек.

**4. Перезагрузите Pi** (`sudo reboot`). Теперь он загружается сразу в плеер;
консольный вход на tty1 выключен, он делил бы экран с плеером. Если плеер
нужен только по команде, ставьте с `--no-autostart`.

Через ~8 секунд после старта службы на экране плеер. Вставьте флешку — она
появится в SOURCE как USB1.

- **Пульт** можно подключить и позже: пока его нет, служба пробует снова
  каждые несколько секунд.
- Если **плеер закрылся или упал**, через 3 секунды он запускается заново.
- **Остановить**: `sudo systemctl stop xdjaz` (до следующей загрузки). Совсем
  без автозапуска: `sudo systemctl disable xdjaz && sudo systemctl enable getty@tty1`.
- Консоль Pi при работающем плеере — по SSH.

## Что работает

- **Пульт.** Все кнопки дек, пэды, джог (скретч, pitch bend, поиск), темпо,
  лупы, hot cue, BEAT SYNC / MASTER, KEY SYNC, SLIP, QUANTIZE, браузер.
  Светодиоды — по состоянию плеера, как на AZ. При запуске плеер сразу знает
  положения всех ручек и фейдеров (пульт присылает их по запросу).
- **4 деки на GRV6.** Кнопка DECK переключает сторону на деку 3/4, плеер
  переключается вместе с ней.
- **Микшер.** Trim, 3-полосный изолятор, фейдеры, кроссфейдер (каналы 1/3 на A,
  2/4 на B), CUE, индикаторы уровня на пульте.
- **COLOR FX.** Нажатие SMART CFX — вкл/выкл, с SHIFT — следующий эффект.
  На GRV6 — ручка на каждом канале.
- **Beat FX.** Все 14 эффектов плеера, доля, уровень, канал. На канале эффект
  стоит после фейдера: убрали фейдер — хвост эха остаётся. Восемь лампочек
  долей на GRV6 показывают выбранную долю.
- **Наушники.** FLX4: смешивает наш микшер (ручки HEADPHONES MIX и LEVEL).
  GRV6 смешивает наушники сам и получает чистую шину CUE.
- **Флешки** вставляются и вынимаются на ходу. Флешка монтируется только для
  чтения, плеер пишет в копию базы в памяти: ваша флешка не меняется.

### Неочевидная раскладка

| Пульт | На AZ |
|---|---|
| Режимы пэдов HOT CUE, BEAT JUMP | как подписано |
| PAD FX1 / STEMS | BEAT LOOP |
| SAMPLER | SLIP LOOP |
| SHIFT + BEAT JUMP (BEAT LOOP) | BEAT LOOP |
| 4 BEAT / EXIT | 4-тактная петля, а если петля играет — выход из неё |
| SMART FADER (FLX4), DISCOVER (GRV6) | SOURCE |
| VIEW (GRV6) | BROWSE |
| Наклон браузера (GRV6) | вверх/вниз — строка (с SHIFT — страница), влево — BACK, вправо — выбор |
| SHIFT + SLIP (VINYL) | JOG MODE |
| SHIFT + MEMORY | удалить метку |
| Рычаг DRUM RELEASE (GRV6) | пока наклонён, канал деки тормозит до остановки, как пластинка |
| Ручка Beat FX (GRV6): LC ECHO, PITCH, MOBIUS saw, MOBIUS tri | PING PONG, TRIPLET FILTER, MOBIUS, TRIPLET ROLL (этих четырёх у AZ нет) |
| BEAT < > | 1/8, 1/4, 1/2, 3/4, 1, 2, 4, 8 |
| SHIFT + SMART FADER (FLX4) / SHIFT + BACK (GRV6), держать 2 с | возврат в меню выбора системы, если на Pi несколько DJ-систем под нашим лаунчером; иначе ничего |

## AZ-MODS

С `--azmods` плеер работает с модами: их `azmod.so` и `azstem.so`
подгружаются в него так же, как на AZ. В SOURCE появляется **MOD MENU**.
Стемы: включите Stems в меню и сделайте стемы в их программе на компьютере —
она положит их на флешку в `STEMS/`. Загрузчик модов с флешки, их
автообновление и SSH здесь не используются; моды ставит `setup-pi.sh`,
для обновления запустите его с новым архивом.

Без модов: `AZMODS=0` (см. [Настройки](#настройки)).

## Настройки

Переменные окружения службы. Создайте
`/etc/systemd/system/xdjaz.service.d/local.conf`:

```ini
[Service]
Environment=PANEL=fit
```

затем `sudo systemctl daemon-reload && sudo systemctl restart xdjaz`.

| Переменная | Значения |
|---|---|
| `PANEL` | как интерфейс 1280×800 ложится на экран 1024×600: `juce` (по умолчанию: точные пропорции, полосы по бокам), `fit` (на весь экран, по высоте сжато на 6%), `stretch`, `panel`. Подробно — `src/docs/panel.md` |
| `REFRESH` | частота экрана, по умолчанию 59.24 Гц, как у AZ: на ней волны идут ровнее всего |
| `COMP` | композитор: `0` нет, `glx`, `xrender`; с AZ-MODS по умолчанию `glx` |
| `AZMODS` | `0` — плеер без модов |
| `AZ_CARD` | имя звуковой карты пульта, если автоопределение ошибается |

## Другой экран

Под панель 1024×600 в `/opt/xdjaz/xorg-az.conf` (исходник —
`src/probe/xorg-az.conf`) настроены три вещи:

- `Modeline` и `PreferredMode` — режим панели. Для другого экрана уберите их
  (X возьмёт режим из EDID) и поставьте `PANEL=panel`, если экран сам
  умеет 1280×800.
- `CalibrationMatrix` поворачивает касания на 180°: у нашей панели сенсор
  повёрнут относительно картинки. Если касания попадают куда надо и без неё,
  удалите эту секцию.
- `kmsdev /dev/dri/card1` — видеовыход Pi 5, не трогайте.

Масштаб, в котором плеер рисует себя, задаёт `src/probe/dconf` (6 из 8 = 0.75).

## Как это устроено

```
 пульт (MIDI) ──► azbridge ──UCOM-кадры──► azshim ─┐
       ▲             │                              │   EP147 (плеер AZ 1.30)
       └── LED ◄─────┘◄──── TX-кадры (светодиоды) ──┤   в bwrap, корень = /opt/xdjaz/rootfs
                                                    │
 звук пульта ◄── azmix ◄── snd-aloop "ALPHATHETAD810" ◄── 8 каналов дек + предпрослушка
```

| Программа | Что заменяет |
|---|---|
| `EP147` | сам плеер из прошивки, без изменений. Работает в `bwrap`: свой корень, пользователь 0 в своём пространстве имён, без сети, минимальный `/dev` |
| `azshim.so` | ядро AZ: подключает плеер к мосту вместо микроконтроллеров, события флешек, ключ OneLibrary, мелкие правки отрисовки |
| `azbridge` | микроконтроллеры панели AZ: из MIDI пульта — кадры кнопок и ручек, из кадров плеера — светодиоды пульта. Он же ведёт Beat FX, как процессор микшера AZ |
| `azmix` | аппаратный микшер AZ: EQ, COLOR FX, фейдеры, Beat FX, CUE — на звуковую карту пульта в реальном времени |
| `aztouch` | фильтр сбоев сенсора панели |
| `azvsync` | время кадров экрана, по которому плеер рисует |
| `xdjaz-usb.sh` | горячая замена флешек |
| `xdjaz-prep.sh`, `xdjaz.service` | звуковая петля на часах пульта, запуск и остановка |

Протокол микроконтроллеров AZ (кадры UCOM) описан в
`src/bridge/UCOM-PROTOCOL.md` (на английском).

## Репозиторий

```
scripts/extract-rootfs.sh  образ 1.30 -> файловая система плеера (на любом Linux)
scripts/setup-pi.sh        установка на Pi
systemd/xdjaz.service      служба: плеер при загрузке, перезапуск, ожидание пульта
src/                       исходники наших программ
make-kit.sh                для автора: обновляет src/ из рабочей копии автора
```

`extract-rootfs.sh` работает и сам по себе:
`./scripts/extract-rootfs.sh XDJAZv130.iso ./rootfs` — достаёт из образа
`images/images.tar.gz`, из него ядро деки, из ядра — встроенный initramfs
(это и есть вся система AZ) и проверяет md5 плеера.

## Если что-то не так

| Где | Что |
|---|---|
| `journalctl -u xdjaz` | запуск и остановка службы |
| `/opt/xdjaz/ep147.log` | вывод плеера |
| `/opt/xdjaz/bridge/azbridge.log` | пульт: какой найден, подключение кадров, нераспознанные сообщения |
| `/opt/xdjaz/mixer/azmix.log` | звук |
| `/opt/xdjaz/xdjaz-usb.log` | флешки |
| `/opt/xdjaz/xorg.log` | экран |

- **Плеера нет, в журнале повторяется `no controller`** — пульт не подключён
  или не определился как звуковая карта (`cat /proc/asound/cards` должен
  показать `DDJGRV6` или `DDJFLX4`).
- **На флешке только папки** — нет ключа OneLibrary
  (`/opt/xdjaz/keys/onelibrary.key`) или на флешке нет `exportLibrary.db`
  (сделайте экспорт свежим rekordbox).
- **Подозрение на моды** — `AZMODS=0`.
- **Снимок экрана** без камеры: `/opt/xdjaz/tools/shot.py out.png`.
- **Нажать кнопки пульта из консоли**: добавьте в `local.conf`
  `Environment="AZBRIDGE_OPTS=-t /opt/xdjaz/bridge/tx.log -i /opt/xdjaz/state/azbridge.in"`;
  тогда `echo "96 41 7F" > /opt/xdjaz/state/azbridge.in` — как будто сообщение
  пришло с пульта, а в `tx.log` пишется всё, что шлёт плеер.

## Ограничения

- Только прошивка **1.30**: правки и раскладки сделаны под эту сборку плеера
  (md5 `3518275e8b4d5d63636d8d7b4468d7ba`), другую скрипт не примет.
- Плеер работает без сети: нет стриминга, Pro DJ Link, обновлений.
- Нет Bluetooth и автоматического сна.
- Подсказку «1/3 1/2 2/3» на панели BEAT FX рисует сам плеер; кнопками
  BEAT < > на 1/3 и 2/3 не попасть.

## Правовое

В репозитории только собственные программы, скрипты и документация. В нём нет
прошивки, частей плеера, ключей и файлов AZ-MODS, и добавлять их нельзя.
Нужна своя копия прошивки, за законность её использования отвечаете вы.
Проект не связан с AlphaTheta и Pioneer DJ; XDJ-AZ, DDJ-GRV6, DDJ-FLX4 и
rekordbox — их товарные знаки. AZ-MODS — отдельный проект со своей лицензией
(GPL-3.0).
