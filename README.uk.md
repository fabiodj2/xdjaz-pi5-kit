# XDJ-AZ на Raspberry Pi 5

[English](README.md) · [Русский](README.ru.md) · **Українська**

Штатний плеєр XDJ-AZ (прошивка **1.30**) на Raspberry Pi 5 з контролером
**DDJ-GRV6** (4 деки) або **DDJ-FLX4** (2 деки). Це той самий плеєр, що працює
в самому AZ: його екран, браузер бібліотеки rekordbox, хвилі, hot cue, лупи,
Beat FX, синхронізація. Усе, чого в Pi немає порівняно з AZ (мікроконтролери
панелі, апаратний мікшер, ядро деки), замінюють програми з цього репозиторію.

Від «у мене є образ 1.30» до Pi, який завантажується одразу в плеєр, — одна
команда.

## Що знадобиться

| | |
|---|---|
| Raspberry Pi 5 | 4 або 8 ГБ; карта або SSD від 32 ГБ (плеєр сам створює собі кеші на ~10 ГБ) |
| Raspberry Pi OS Lite **64-bit** (Debian 13 trixie) | без робочого столу: екран і контролер тримає плеєр. Користувач із `sudo` без пароля (так у першого користувача Pi OS за замовчуванням), у групах `audio`, `video`, `input` |
| Екран | HDMI; налаштовано під сенсорну панель 1024×600. Інший екран — див. [Інший екран](#інший-екран) |
| Контролер | DDJ-GRV6 або DDJ-FLX4 по USB. Якщо під'єднано обидва, береться GRV6 |
| Образ прошивки | `XDJAZv130.iso` — **розшифрований** образ оновлення 1.30 (ISO 9660, мітка `UsbAuto`). Не входить до репозиторію |
| Ключ OneLibrary | файл з одним рядком. Без нього на флешці видно лише теки, без плейлистів і бібліотеки. Ключ один для всіх дек; наш узято з проєкту [AZ-MODS](https://github.com/Kyle-Hosman/xdj-az-mods), який ним відкриває бібліотеку у своєму емуляторі. Не входить до репозиторію |
| Флешка | експорт rekordbox з OneLibrary (`PIONEER/rekordbox/exportLibrary.db`); старий `export.pdb` плеєр 1.30 не читає |
| AZ-MODS (за бажанням) | `mods-vX.Y.Z.tar.gz` з релізів [AZ-MODS](https://github.com/Kyle-Hosman/xdj-az-mods): Mod Menu, стеми, редагування плейлистів, теми |

## Швидкий старт

**1. Pi.** Запишіть Raspberry Pi OS Lite 64-bit через Raspberry Pi Imager,
увімкніть SSH. Завантажтеся, під'єднайте екран і контролер.

**2. Репозиторій, образ і ключ на Pi** (`pi` — адреса вашого Pi):

```sh
ssh pi git clone https://github.com/r1x0s/xdjaz-pi5-kit
scp XDJAZv130.iso onelibrary.key pi:
scp mods-v1.2.8.tar.gz pi:          # для AZ-MODS
```

**3. Встановлення** (на Pi):

```sh
cd ~/xdjaz-pi5-kit
sudo ./scripts/setup-pi.sh --iso ~/XDJAZv130.iso --key ~/onelibrary.key
#   + --azmods ~/mods-v1.2.8.tar.gz   для AZ-MODS
```

Скрипт ставить пакети, дістає з образу файлову систему плеєра в
`/opt/xdjaz/rootfs` (і перевіряє, що це 1.30), збирає наші програми просто
на Pi, розкладає все по `/opt/xdjaz` і ставить службу `xdjaz.service`.
Кілька хвилин, здебільшого `apt`. Запускати можна повторно: перезбирає й
перевстановлює все, крім самого плеєра та його налаштувань.

**4. Перезавантажте Pi** (`sudo reboot`). Тепер він завантажується одразу в
плеєр; консольний вхід на tty1 вимкнено, бо він ділив би екран із плеєром.
Якщо плеєр потрібен лише за командою, ставте з `--no-autostart`.

За ~8 секунд після старту служби на екрані плеєр. Вставте флешку — вона
з'явиться в SOURCE як USB1.

- **Контролер** можна під'єднати й пізніше: поки його немає, служба пробує
  знову кожні кілька секунд.
- Якщо **плеєр закрився або впав**, за 3 секунди він запускається знову.
- **Зупинити**: `sudo systemctl stop xdjaz` (до наступного завантаження).
  Зовсім без автозапуску: `sudo systemctl disable xdjaz && sudo systemctl enable getty@tty1`.
- Консоль Pi під час роботи плеєра — через SSH.

## Що працює

- **Контролер.** Усі кнопки дек, пади, джог (скретч, pitch bend, пошук),
  темпо, лупи, hot cue, BEAT SYNC / MASTER, KEY SYNC, SLIP, QUANTIZE,
  браузер. Світлодіоди — за станом плеєра, як на AZ. Під час запуску плеєр
  одразу знає положення всіх ручок і фейдерів (контролер надсилає їх на запит).
- **4 деки на GRV6.** Кнопка DECK перемикає сторону на деку 3/4, плеєр
  перемикається разом із нею.
- **SHIFT** будь-якої сторони працює на обох деках, як на AZ.
- **Мікшер.** Trim, EQ, фейдери, кросфейдер, CUE, індикатори рівня на
  контролері. Він слідує екрану MIXER SETTINGS плеєра: призначення кросфейдера
  по каналах (в AZ за замовчуванням THRU на всіх чотирьох — поставте там A/B,
  щоб кросфейдер працював), криві кросфейдера й фейдерів, EQ або ISO,
  MONO SPLIT у навушниках, гучність попереднього прослуховування LINK.
- **COLOR FX.** Натискання SMART CFX — увімк./вимк., із SHIFT — наступний
  ефект. На GRV6 — ручка на кожному каналі.
- **Beat FX.** Усі 14 ефектів плеєра, доля, рівень, канал. На каналі ефект
  стоїть після фейдера: прибрали фейдер — хвіст луни лишається. Вісім
  лампочок доль на GRV6 показують вибрану долю.
- **Навушники.** FLX4: змішує наш мікшер (ручки HEADPHONES MIX і LEVEL).
  GRV6 змішує навушники сам і отримує чисту шину CUE. Попереднє
  прослуховування треку в браузері звучить лише в навушниках, як на AZ.
- **Мікрофон.**
  - FLX4: мікрофон іде через наш мікшер: MIC LEVEL, talkover (UTILITY >
    Mixer; вмикається голосом, Normal або Advanced), Feedback Reducer
    (MIXER SETTINGS). SHIFT + важіль FX CH ставить Beat FX лише на мікрофон.
  - GRV6: контролер сам підмішує мікрофон у свій мастер; ефектів і рівня
    звідси в нього немає.
- **MASTER REC** записує мастер, як він звучить, на флешку в теку
  `ALPHATHETA REC` (WAV, 44.1 кГц). З увімкненим MIC Output to Master REC у
  запис із GRV6 потрапляє й мікрофон.
- **Флешки** вставляються й виймаються на ходу. Для плеєра флешка лише для
  читання, крім теки `ALPHATHETA REC`; зміни бази плеєр пише в копію в
  пам'яті, тож бібліотека на флешці не змінюється.
- **Сон.** Коли контролер переходить в очікування (його Auto Standby), плеєр
  засинає разом із ним: екран чорний. Розбудіть контролер — за ~10 с плеєр
  знову на екрані, флешки в SOURCE; завантажені треки вивантажено, як після
  сну AZ.

### Неочевидна розкладка

| Контролер | На AZ |
|---|---|
| Режими падів HOT CUE, BEAT JUMP | як підписано |
| PAD FX1 / STEMS | BEAT LOOP |
| SAMPLER | SLIP LOOP |
| SHIFT + BEAT JUMP (BEAT LOOP) | BEAT LOOP |
| 4 BEAT / EXIT | 4-тактна петля, а якщо петля грає — вихід із неї |
| SMART FADER (FLX4), DISCOVER (GRV6) | SOURCE |
| VIEW (GRV6) | BROWSE |
| Нахил браузера (GRV6) | вгору/вниз — рядок (із SHIFT — сторінка), ліворуч — BACK, праворуч — вибір |
| SHIFT + SLIP (VINYL) | JOG MODE |
| SHIFT + важіль FX CH (FLX4) | Beat FX лише на мікрофоні; важіль без SHIFT повертає на канал |
| SHIFT + MEMORY | видалити мітку |
| Важіль DRUM RELEASE (GRV6) | поки нахилений, канал деки гальмує до зупинки, як платівка |
| Ручка Beat FX (GRV6): LC ECHO, PITCH, MOBIUS saw, MOBIUS tri | PING PONG, TRIPLET FILTER, MOBIUS, TRIPLET ROLL (цих чотирьох в AZ немає) |
| BEAT < > | 1/8, 1/4, 1/2, 3/4, 1, 2, 4, 8 |
| SHIFT + SMART FADER (FLX4) / SHIFT + BACK (GRV6), тримати 2 с | повернення до меню вибору системи, якщо на Pi кілька DJ-систем під нашим лаунчером; інакше нічого |

## AZ-MODS

З `--azmods` плеєр працює з модами: їхні `azmod.so` і `azstem.so`
підвантажуються в нього так само, як на AZ. У SOURCE з'являється
**MOD MENU**. Стеми: увімкніть Stems у меню й зробіть стеми в їхній програмі
на комп'ютері — вона покладе їх на флешку в `STEMS/`. Завантажувач модів із
флешки, їхнє автооновлення та SSH тут не використовуються; моди ставить
`setup-pi.sh`, для оновлення запустіть його з новим архівом.

Без модів: `AZMODS=0` (див. [Налаштування](#налаштування)).

## Налаштування

Змінні оточення служби. Створіть
`/etc/systemd/system/xdjaz.service.d/local.conf`:

```ini
[Service]
Environment=PANEL=fit
```

потім `sudo systemctl daemon-reload && sudo systemctl restart xdjaz`.

| Змінна | Значення |
|---|---|
| `PANEL` | як інтерфейс 1280×800 лягає на екран 1024×600: `juce` (за замовчуванням: точні пропорції, смуги з боків), `fit` (на весь екран, по висоті стиснуто на 6%), `stretch`, `panel`. Докладно — `src/docs/panel.md` (російською) |
| `REFRESH` | частота екрана, за замовчуванням 59.24 Гц, як в AZ: на ній хвилі йдуть найрівніше |
| `COMP` | композитор: `0` немає, `glx`, `xrender`; з AZ-MODS за замовчуванням `glx` |
| `AZMODS` | `0` — плеєр без модів |
| `AZ_CARD` | ім'я звукової карти контролера, якщо автовизначення помиляється |
| `AZ_SLEEP` | `0` — не засинати разом із контролером (тоді плеєр закривається, коли контролер зникає) |

## Інший екран

Під панель 1024×600 у `/opt/xdjaz/xorg-az.conf` (вихідник —
`src/probe/xorg-az.conf`) налаштовано три речі:

- `Modeline` і `PreferredMode` — режим панелі. Для іншого екрана приберіть їх
  (X візьме режим з EDID) і поставте `PANEL=panel`, якщо екран сам уміє
  1280×800.
- `CalibrationMatrix` повертає дотики на 180°: у нашої панелі сенсор
  повернутий відносно картинки. Якщо дотики влучають куди треба й без неї,
  видаліть цю секцію.
- `kmsdev /dev/dri/card1` — відеовихід Pi 5, не чіпайте.

У `src/probe/run-probe.sh` фільтр дотиків `aztouch` запускається для панелі
1024×600, повернутої на 180° (`-S 1024x600 -r`), і з `PANEL=juce` збільшує
дрібні значки біля краю верхнього рядка (таймер REC, шестерня) — зони `-z`.
Для іншого екрана виправте або приберіть їх.

Масштаб, у якому плеєр малює себе, задає `src/probe/dconf` (6 з 8 = 0.75).

## Як це влаштовано

```
 контролер (MIDI) ──► azbridge ──UCOM-кадри──► azshim ─┐
        ▲                │                              │   EP147 (плеєр AZ 1.30)
        └── LED ◄────────┘◄──── TX-кадри (світлодіоди) ─┤   у bwrap, корінь = /opt/xdjaz/rootfs
                                                        │
 звук контролера ◄── azmix ◄── snd-aloop "ALPHATHETAD810" ◄── 8 каналів дек + попереднє прослуховування
```

| Програма | Що замінює |
|---|---|
| `EP147` | сам плеєр із прошивки, без змін. Працює в `bwrap`: свій корінь, користувач 0 у власному просторі імен, без мережі, мінімальний `/dev` |
| `azshim.so` | ядро AZ: під'єднує плеєр до моста замість мікроконтролерів, події флешок, ключ OneLibrary, дрібні виправлення відмальовування |
| `azbridge` | мікроконтролери панелі AZ: із MIDI контролера — кадри кнопок і ручок, із кадрів плеєра — світлодіоди контролера. Він же веде Beat FX, як процесор мікшера AZ |
| `azmix` | апаратний мікшер AZ: EQ, COLOR FX, фейдери, Beat FX, CUE — на звукову карту контролера в реальному часі |
| `aztouch` | фільтр збоїв сенсора панелі |
| `azvsync` | час кадрів екрана, за яким плеєр малює |
| `xdjaz-usb.sh` | гаряча заміна флешок |
| `xdjaz-prep.sh`, `xdjaz.service` | звукова петля на годиннику контролера, запуск і зупинка |

Протокол мікроконтролерів AZ (кадри UCOM) описано в
`src/bridge/UCOM-PROTOCOL.md` (англійською).

## Репозиторій

```
scripts/extract-rootfs.sh  образ 1.30 -> файлова система плеєра (на будь-якому Linux)
scripts/setup-pi.sh        встановлення на Pi
systemd/xdjaz.service      служба: плеєр під час завантаження, перезапуск, очікування контролера
src/                       вихідні коди наших програм
make-kit.sh                для автора: оновлює src/ з робочої копії автора
```

`extract-rootfs.sh` працює й окремо:
`./scripts/extract-rootfs.sh XDJAZv130.iso ./rootfs` — дістає з образу
`images/images.tar.gz`, із нього ядро деки, з ядра — вбудований initramfs
(це і є вся система AZ) і перевіряє md5 плеєра.

## Якщо щось не так

| Де | Що |
|---|---|
| `journalctl -u xdjaz` | запуск і зупинка служби |
| `/opt/xdjaz/ep147.log` | вивід плеєра |
| `/opt/xdjaz/bridge/azbridge.log` | контролер: який знайдено, під'єднання кадрів, нерозпізнані повідомлення |
| `/opt/xdjaz/mixer/azmix.log` | звук |
| `/opt/xdjaz/xdjaz-usb.log` | флешки |
| `/opt/xdjaz/xorg.log` | екран |

- **Плеєра немає, у журналі повторюється `no controller`** — контролер не
  під'єднано або він не визначився як звукова карта (`cat /proc/asound/cards`
  має показати `DDJGRV6` або `DDJFLX4`).
- **На флешці лише теки** — немає ключа OneLibrary
  (`/opt/xdjaz/keys/onelibrary.key`) або на флешці немає `exportLibrary.db`
  (зробіть експорт свіжим rekordbox).
- **Підозра на моди** — `AZMODS=0`.
- **Знімок екрана** без камери: `/opt/xdjaz/tools/shot.py out.png`.
- **Натиснути кнопки контролера з консолі**: додайте в `local.conf`
  `Environment="AZBRIDGE_OPTS=-t /opt/xdjaz/bridge/tx.log -i /opt/xdjaz/state/azbridge.in"`;
  тоді `echo "96 41 7F" > /opt/xdjaz/state/azbridge.in` — ніби повідомлення
  прийшло з контролера, а в `tx.log` пишеться все, що надсилає плеєр.

## Обмеження

- Лише прошивка **1.30**: виправлення й розкладки зроблено під цю збірку
  плеєра (md5 `3518275e8b4d5d63636d8d7b4468d7ba`), іншу скрипт не прийме.
- Плеєр працює без мережі: немає стримінгу, Pro DJ Link, оновлень.
- Немає Bluetooth.
- Немає лімітера: гучні треки кліпують, якщо TRIM вище середини.
- Підказку «1/3 1/2 2/3» на панелі BEAT FX малює сам плеєр; кнопками
  BEAT < > на 1/3 і 2/3 не потрапити.

## Правове

У репозиторії лише власні програми, скрипти й документація. У ньому немає
прошивки, частин плеєра, ключів і файлів AZ-MODS, і додавати їх не можна.
Потрібна власна копія прошивки, за законність її використання відповідаєте ви.
Проєкт не пов'язаний з AlphaTheta і Pioneer DJ; XDJ-AZ, DDJ-GRV6, DDJ-FLX4 і
rekordbox — їхні торговельні марки. AZ-MODS — окремий проєкт із власною
ліцензією (GPL-3.0).
